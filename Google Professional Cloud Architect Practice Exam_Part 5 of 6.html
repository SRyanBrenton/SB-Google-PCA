An application development team asks you for advice. They plan to develop and deploy an HTTP(S) API with Go 1.12. The API will experience a highly unpredictable workload and must stay reliable during traffic peaks. They want to minimize operational overhead for this application. Which approach should you recommend?

Explanation

App Engine standard environment is a fully managed platform for Go 1.12+ web services. It provides automatic scaling, creating instances as needed for incoming load while avoiding the cluster or virtual-machine management required by Google Kubernetes Engine or Compute Engine managed instance groups. A custom flexible-environment runtime is not needed for Go 1.12.

Verified/Designing for security and compliance

You work for an institution that handles medical data and are migrating several workloads to Google Cloud. Company policies mandate that all workloads run on physically separate hardware, with workloads from different clients also kept separate. You created a sole-tenant node group and added one node for every client. You need to deploy the workloads on these dedicated hosts. What should you do?

Explanation

A sole-tenant node group can contain multiple physical nodes. To ensure that workloads belonging to different clients are not co-located, each workload must be scheduled to its assigned individual node. Compute Engine uses node affinity for sole-tenant VM placement; network tags do not control host placement.

QuestionQ329

Verified/Designing and planning a cloud solution architecture

Your company has recently acquired another company, and you have been asked to integrate its existing Google Cloud environment with your company’s data center. During the investigation, you find that some RFC 1918 IP ranges used in the acquired company’s Virtual Private Cloud (VPC) overlap with IP space in your data center. What should you do to enable connectivity and ensure that no routing conflicts occur when the connection is established?

Explanation

Hybrid connectivity requires non-overlapping VPC and on-premises IP address spaces for traffic to route correctly. A Cloud VPN with Cloud Router provides the connectivity and dynamic route exchange, while assigning new, non-overlapping VPC addresses removes the route ambiguity. Blocking advertisements or traffic does not make the overlapping destinations uniquely routable.

QuestionQ330

Verified/Designing for security and compliance

You are designing a mobile chat application and want to ensure that people cannot spoof chat messages by demonstrating that a message was sent by a particular user.

What should you do?

Explanation

PKI supports digital signatures: the originating user applies their private key to authenticate a message, and recipients verify it with that user’s public key. This provides cryptographic proof of the sender’s identity and makes impersonation substantially harder.

QuestionQ331

Verified/Designing for security and compliance

You are designing a data warehouse on Google Cloud and need to store sensitive data in BigQuery. Your company requires that the encryption keys be generated outside Google Cloud. You need to implement a solution. What should you do?

Explanation

Cloud KMS supports importing cryptographic key material generated outside Google Cloud, allowing it to be used as a customer-managed encryption key. BigQuery does not support customer-supplied encryption keys (CSEK); its supported customer-controlled encryption approach uses Cloud KMS customer-managed encryption keys (CMEK).

QuestionQ335

Verified/Ensuring solution and operations excellence

Refer to the TerramEarth case study for this question.

TerramEarth has a legacy web application that cannot be migrated to the cloud. However, you still want to create a cloud-native way to monitor the application. If the application becomes unavailable, you want the URL to point to a "Site is unavailable" page as quickly as possible. You also want the Ops team to receive a notification about the issue. You need to create a reliable solution at minimum cost. What should you do?

Explanation

Cloud Monitoring uptime checks test the availability of an internet-accessible URL, and an alerting policy can notify through a Pub/Sub notification channel when the check fails. A Pub/Sub-triggered Cloud Function can perform the URL failover action and notify the Ops team. This uses managed, event-driven services without maintaining a VM or polling container. Cloud Error Reporting is for collecting and analyzing reported application errors, not for checking whether an external URL is reachable.

QuestionQ336

They must remain available for active querying for 30 days; afterward, they only need to be retained for audit purposes. A bucket retention policy, locked with Bucket Lock, makes objects undeletable or unreplaceable until the configured retention period has elapsed, supporting the two-year compliance requirement.

Your company is designing a data lake on Google Cloud and wants to build different ingestion pipelines to collect unstructured data from multiple sources.

After the data is stored in Google Cloud, it will be processed by several data pipelines to build a recommendation engine for website end users. The structure of data retrieved from the source systems can change at any time. The data must be stored exactly as retrieved so it can be reprocessed if its structure is incompatible with the current processing pipelines.
